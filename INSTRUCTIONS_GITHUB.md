# Instructions pour envoyer ta partie sur GitHub

Bonjour, voici les fichiers dont tu es responsable pour notre projet VoxAI.

## Ce que tu dois faire :
1. Clone le dépôt commun de notre équipe sur ton ordinateur :
   `git clone https://github.com/YassineEraman/VoxAI.git`
2. Ouvre le dossier cloné :
   `cd VoxAI`
3. Copie tous les dossiers et fichiers fournis dans ton dossier membre (à l'exception de ce fichier d'instructions) et colle-les **à l'intérieur du dossier VoxAI cloné**, en respectant bien l'arborescence.
4. Ajoute tes fichiers avec la commande :
   `git add .`
5. Sauvegarde tes changements :
   `git commit -m "Ajout de la partie Data Engineer"`
6. Envoie le tout sur GitHub :
   `git push`

Et voilà, ta partie sera ajoutée au projet commun !
